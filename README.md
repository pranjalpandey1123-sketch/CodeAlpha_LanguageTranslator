CodeAlpha Language Translator

About the Project

This project is a Language Translator developed as part of the CodeAlpha Artificial Intelligence Internship.

It allows users to translate text from one language to another using an online translation service.

Features

- Select source and target languages.
- Translate text between multiple languages.
- Swap source and target languages.
- Copy translated text.
- Simple and responsive user interface.

Technologies Used

- HTML
- CSS
- JavaScript
- Fetch API
- Google Translate unofficial endpoint

Supported Languages

- English
- Hindi
- Gujarati
- Marathi
- French
- Spanish
- German
- Japanese

How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Enter text and select languages.
5. Click the Translate Now button.

Project Structure

- index.html — Website structure
- style.css — Website design
- script.js — Translation functionality
